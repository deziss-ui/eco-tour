# Enviro Audit – התקנה על הטלפון

האפליקציה מותקנת כ"אפליקציית ווב" (PWA): אייקון במסך הבית, נפתחת במסך מלא בלי דפדפן, עובדת גם בלי קליטה, והנתונים נשמרים בטלפון בלבד.

## שלב 1 – העלאה לאתר חינמי (פעם אחת, מהמחשב, כ-10 דקות)
1. נכנסים ל-github.com ופותחים חשבון (אם אין).
2. לוחצים New repository, נותנים שם `eco-tour`, ובוחרים Public. אחר כך Create repository.
3. במסך שנפתח: uploading an existing file. גוררים את **כל הקבצים שבתיקייה הזו** (לא את התיקייה עצמה) ולוחצים Commit changes.
4. Settings ← Pages ← תחת Branch בוחרים `main` ו-`/ (root)` ← Save.
5. אחרי דקה-שתיים הכתובת תופיע למעלה, בצורה `https://<שם-המשתמש>.github.io/eco-tour/`

## שלב 2 – התקנה בטלפון (אנדרואיד)
1. פותחים את הכתובת ב-Chrome.
2. תפריט ⋮ ← "התקנת אפליקציה" (או "הוספה למסך הבית").
3. מעכשיו פותחים מהאייקון "Enviro Audit".

## העברת סיורים מהגרסה הקודמת
בגרסה שב-Claude: "גיבוי לקובץ". באפליקציה המותקנת: "שחזור מגיבוי" ובוחרים את הקובץ.

## ניסוח ממצאים עם Claude (לא חובה)
הגדרות ← מפתח API של Anthropic (מ-console.anthropic.com). כל ניסוח עולה סנטים בודדים ודורש אינטרנט. בלי מפתח כל השאר עובד.

## עדכון גרסה
מעלים את הקבצים החדשים לאותו מאגר ב-GitHub (מחליפים את הישנים). בפתיחה הבאה עם אינטרנט האפליקציה מתעדכנת. הנתונים בטלפון לא נמחקים.

## חשוב
- הקוד במאגר ציבורי, אבל הסיורים והתמונות לא עולים לשום מקום. הם נשמרים רק בטלפון.
- לא למחוק "נתוני אתר" של הכתובת בהגדרות Chrome. זה ימחק את הסיורים.
- מומלץ לגבות לקובץ מדי פעם.
